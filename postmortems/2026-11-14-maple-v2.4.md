## Summary
Release v2.4 introduced a prompt change that caused Maple to answer exclusively from memory while disabling the search tool. This version was promoted to serve all traffic, resulting in the complete cessation of search tool usage. The system was reverted to the previous revision after an automated alert identified the shift in search behavior.

## Impact
During the operation of version v2.4, 75 answers were provided with 0% search tool usage, compared to 77% in the previous version. The incident lasted 251 seconds from the first bad answer to the alert, and 253 seconds from the first bad answer to the rollback.

## Five whys
1. Why did Maple stop using the search tool? Version v2.4 included a prompt change that instructed the system to answer from memory and never call the search tool.
2. Team to answer: Why was the prompt change in v2.4 not identified as a breaking change prior to promotion?
3. Team to answer: How can the automated testing suite be updated to verify that the search tool remains functional after prompt updates?
4. Team to answer: What prevents the system from automatically gating the deployment of versions that show a 100% reduction in search tool usage?
5. Team to answer: How can the alert threshold for search tool utilization be optimized to trigger faster than 251 seconds?

## What went well
* The maple-guard service successfully redirected 100% of traffic back to the champion revision upon detection.
* An automated alert was configured to identify and monitor the share of answers that skipped the search tool.

## Action items
* ML Engineer: Develop a regression test suite that mandates search tool usage for queries requiring external knowledge.
* SRE: Review the alert latency to determine if threshold configurations can safely reduce the time to detection below 251 seconds.
* ML Engineer: Implement an automated canary analysis step that compares search tool invocation rates between the current and new versions before full traffic promotion.
* SRE: Document the maple-guard traffic routing logic to ensure rapid emergency intervention protocols are well-understood.
